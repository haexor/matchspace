Szene

    Die Buchstaben sind die Boxen der Auswertung, nicht die echten Spieler. Frage für jede Box nach der Marke: Auf wem sitzt sie jetzt, und welche Box saß vorher auf ihm? Beispiel: Box B springt zum Spieler, den vorher Box A hatte (Box A hat dann keine Person mehr) → bei „Box B nachher“ wählen: Box A vorher. Die Linie zeigt den Weg jeder Box. Eine Lücke (keine Box für ein paar Bilder) ist kein Fehler, ein Sprung auf eine andere Person ist einer. Nicht erkennbar: U.
